⚠ screen size not from eqclient.ini

Arrange your windows on screen

1. Open layout .ini and choose a loadout file from your EverQuest folder, such as UI_<character>_<server>_LO1.ini. You can pick several loadouts at once. Pick eqclient.ini from the same folder too: it holds the screen size EverQuest uses (with your Windows display scaling already applied), which every window position depends on.

2. Optional but recommended: Open uifiles folder. Windows then show your skin's real artwork, and windows that don't store a size get the correct one.

Files are only read. Saving gives you a .zip with the new loadout file plus an untouched backup of the original.

Edit your EverQuest windows visually

Choose your uifiles folder, the one inside your EverQuest folder. Every skin inside it shows up in the Skin menu, and any file a skin is missing falls back to default, the same way the game does.

Your files are only read. Nothing is written back to your game folder: Save gives you a .zip with the edited files plus a backup copy of every original they replace.

Save layout

The .zip holds the new file, plus a _backup folder with the original of every loaded file it could replace. Close EverQuest, or sit at character select, before copying it in: the game rewrites this file when you camp or exit, and would overwrite your changes.
